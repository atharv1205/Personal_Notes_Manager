# 📝 NoteNest

**NoteNest** is a personal note-taking web app built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js).

It allows users to:
- Sign up and log in securely
- Create, update, and delete their own notes
- Manage their profile

> 🚧 This project is still in progress.  
> ✅ Core features are working, but more functionality and styling are being added soon!

---

## 🔧 Tech Used

- **Frontend:** React.js, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (token stored in cookies)

---

## 🛠 Current Features

- ✅ User Signup and Login
- ✅ Secure JWT authentication
- ✅ Add, edit, delete personal notes
- ✅ User profile section
